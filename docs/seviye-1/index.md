# Seviye 1: İletişim

Seviye 1 bittiğinde kişi kendi paketinde, kendi tanımladığı mesaj tipiyle konuşan iki node yazar ve oluşan grafiği sözlü olarak anlatır. Tahmini süre: 7 saat (Çekirdek 6, Genişletme 1). Nötr senaryo: bir hava istasyonu. Bir node sıcaklık yayınlar, öteki dinler ve eşik aşılınca uyarır.
