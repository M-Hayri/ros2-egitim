# Sözlük

Her terim için tek kart: tek cümlelik tanım, ne zaman kullanılır, sık karıştırılan terim ve terimin geçtiği ders. Toplantıda başvuru kaynağı olarak kullanılır.

!!! note "Sözlük dersler yazıldıkça dolacak"
    Her ders sayfası, sözlüğe eklediği terimleri listeler.

## Kart biçimi

| Alan | Örnek |
| --- | --- |
| Terim | Servis |
| Tanım | Tek seferlik soru-cevap biçiminde iletişim. |
| Ne zaman | İstek kısa sürede cevaplanacaksa. |
| Karıştırılan | Action: uzun süren, ara durum bildiren, iptal edilebilen işler için. |
| Ders | 2.1 |
