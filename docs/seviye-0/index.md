# Seviye 0: Giriş

Seviye 0 bittiğinde kişi kurulum yapmadan bir ROS ortamı açar, turtlesim'i yönetir ve ROS'un neden programları küçük parçalara böldüğünü kendi cümleleriyle anlatır. Tahmini süre: 3 saat. Önkoşul: Linux ve git uyum kaynakları (Missing Semester ilk iki ders, Bandit ilk 10 seviye).

Codespace'te turtlesim ve teleop çalışıyor. Ortam betik kontrolü yeşil. Koordinatörün sorduğu "`source` ne yapar?" sorusu doğru cevaplanıyor.
